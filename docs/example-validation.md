# Example validation

Validated on 2026-10-05 on macOS with the installed LayoutEditor 20260920 API and an isolated analysis Python.
All input layouts are generated by LayoutEditor. gdstk independently reads exports for checks;
it does not generate the masks. No fabrication or optical performance qualification is implied.

| Example | Inputs and outputs | Executed checks |
|---|---|---|
| Data prep | Kelvin/contact coupon + line/space monitor, both with TOP/PAD names; GDS, DXF, OASIS, remapped and merged GDS | OASIS area/bounds round-trip; remapped areas; preserved independent namespaces and placement bounds |
| Mixed reticle | Resistor monitors + Y-junction/serpentine microfluidic dies; 16×12 mm rectangular field | 25 dies (13 RES, 12 FLUID); 100 µm pairwise separation; field margins; actual street polygons; 78.125% declared die area / gross field area |
| PIC | MZI ΔL=40 µm, ring R=30 µm/gap=200 nm, separate shallow-etch grating, Euler coupon | Three DRC rules, zero violations; five expected core components; all external routes connected; grating slots contained in core; drawn ΔL within 10 nm; bend radius fit within 0.5 µm |
| MEMS | Existing SOI comb actuator with trenches, metal and backside cavity | Nine DRC rules, zero violations; pad isolation and five probes pass; no fully detached region in release test |
| CMOS LVS | Technology file `cmos_tech.json`; NAND2 drawn by layer name in three variants (good, A–B short, missing VIA1) | `pdk_tool.py check`; audit with no undeclared pairs or off-grid points; seven DRC rules, zero violations; native extraction finds 4 MOS and 6 nets (series node unlabelled); LVS PASS for good, FAIL for short and open; labels on 6/2 and 8/2 read back with gdstk |

Nine regression groups in `tests/test_native_contracts.py` check rotated placement and
inspection bounds; namespace collision/missing top failures; missing/oversized source failures;
circular planning with mixed die sizes; layer/datatype inspection and pair remapping in place;
10 nm → 1 nm DBU normalization (paths, arrays, extent) and refusal of a rounding change; audit of
undeclared pairs and off-grid points; extraction with and without an ignored fill datatype; and
SPICE parsing of nested subcircuits, bulk pins and continuation lines plus a swapped-pin failure.
Circular GDS export still needs its own acceptance.

The seven independent tests live in `tests/check_example_outputs.py`. Run after generating examples:

```bash
python tests/check_example_outputs.py /tmp/layout-skill-examples
python tests/test_native_contracts.py /tmp/layout-skill-examples
```

To regenerate layouts, execute checks and refresh every PNG and its manifest:

```bash
python -m pip install numpy pillow matplotlib gdstk
python scripts/update_assets.py /tmp/layout-skill-examples
```

`update_assets.py` sets `PYTHON` to its own interpreter for runners, discovers `LE_PY`, and stops
on a failed runner or output check before copying assets. GDS cell exports may simplify and
reorder polygon vertices; output checks measure geometry rather than assuming vertex indices.

The default data-prep demo skips boolean export. Set `RUN_LICENSED_BOOLEAN=1` only with a license
that permits the requested export. Commercial boolean export was not exercised in this validation.
DXF was written; its lossless round-trip is unverified. Windows/Linux execution and large-wafer
performance remain unverified. The examples contain illustrative dimensions and rules.
